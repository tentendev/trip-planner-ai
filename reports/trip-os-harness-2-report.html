高價值（建議下一輪主力）

  1. 結構化可編輯行程（最大戰略項）：LLM 輸出 schema 化日程物件，讓單活動可拖拽排序、替換、改時間——打卡面板已是其前身，缺的是生成端結構化。研究顯示這是 2026 互動契約的核心。
  2. 貼上訂單解析：貼上航班/飯店確認文字 → LLM 抽取 → 併入行程（TripIt 17 年護城河，LLM 时代門檻已降低）。
  3. 地圖 v2：marker clustering、路線最佳化排序（OSRM 免費層）、暗色瓦片已就緒可再加離線圖層。
  4. 協作分享：唯讀分享已有；下一步是「共同編輯」或至少「分享連結的打卡同步」（CRDT/Yjs 或輪詢 Blob 版本）。

中價值

  1. 旅程記憶 profile：跨行程累積偏好（節奏/飲食/住宿風格）並在表單預填——研究指出 session memory 應立即上、跨行程記憶是留存護城河。
